# Diablo 4 Boosting Platform - MERN Stack

## Quick Start
1. Rename .env.example to .env and fill in your credentials
2. Run: npm install && cd client && npm install && cd ..
3. Run: npm run build && npm start
4. Access admin panel at /admin
